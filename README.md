# Iza Space ✿

Hub pessoal e profissional criado para a Izadora, social media do IBAP-RJ.

A proposta mistura organização de conteúdo, campanhas, métricas, tarefas e vida pessoal em uma interface leve, criativa e girly.

## Abas

- **Home** — visão geral do dia, humor, agenda e resumo de conteúdo.
- **Content Studio** — planejamento semanal e pipeline de publicações.
- **Projects** — acompanhamento de campanhas e projetos do IBAP-RJ.
- **Idea Garden** — banco de ideias com armazenamento local.
- **Analytics** — painel visual de métricas e conteúdos de destaque.
- **Planner** — tarefas separadas por prioridade e status.
- **My Space** — espaço pessoal, wishlist e brain dump.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- localStorage para persistência de humor, ideias, tarefas e anotações

## Como executar

Abra `index.html` diretamente no navegador ou use uma extensão como Live Server.

## Estrutura

```text
HubIza/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Observações

Os dados do painel de analytics e parte da agenda são demonstrativos. As áreas de ideias, tarefas, humor e brain dump são funcionais e ficam salvas no navegador do usuário.
